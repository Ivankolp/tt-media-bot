# TeamTalk Native Media Bot (C++ Edition)

Высокопроизводительный нативный медиа-бот для TeamTalk 5, написанный на C++17.  
Воспроизводит аудио с YouTube и прямых потоков, поддерживает очередь воспроизведения, аудиоэффекты в реальном времени, избранное и выгрузку файлов в канал.

## Установка и запуск

### Системные требования:
- Linux x86_64 или ARM64
- Компилятор `g++` (с поддержкой C++17) и утилита `make`
- `ffmpeg`
- `libcurl4-openssl-dev`, `libsqlite3-dev` и `nlohmann-json3-dev`
- `Node.js` v18+

### 1. Сборка
```bash
make -j$(nproc)
```

### 2. Настройка конфигурации
Скопируйте шаблон конфигурационного файла:
```bash
cp config.example.json config.json
```

Отредактируйте параметры подключения в `config.json` (`hostname`, `tcp_port`, `username`, `password`):
```json
{
    "config_version": 0,
    "general": {
        "language": "ru",
        "send_channel_messages": false,
        "cache_file_name": "bot.db",
        "blocked_commands": [],
        "delete_uploaded_files_after": 300,
        "time_format": "%H:%M",
        "status": "Отправьте h для справки",
        "start_commands": []
    },
    "player": {
        "default_volume": 25,
        "max_volume": 100,
        "volume_fading": false,
        "volume_fading_interval": 0.005,
        "seek_step": 10
    },
    "teamtalk": {
        "hostname": "127.0.0.1",
        "tcp_port": 16815,
        "udp_port": 16815,
        "encrypted": false,
        "nickname": "Музыкальный Бот",
        "status": "Отправьте h для справки",
        "gender": "n",
        "username": "bot_native",
        "password": "your_password",
        "channel": "/",
        "channel_password": "",
        "reconnection_attempts": -1,
        "reconnection_timeout": 5,
        "users": {
            "admins": [
                "admin"
            ],
            "banned_users": []
        }
    },
    "services": {
        "default_service": "yt",
        "bridge_url": "http://127.0.0.1:4417",
        "yt": {
            "enabled": true,
            "search_results": 1
        },
        "ytm": {
            "enabled": true,
            "search_results": 1
        }
    }
}
```

### 3. Запуск
```bash
./run.sh
```

### 4. Автоматическая установка (install.sh)
Скрипт `install.sh` автоматически установит зависимости, настроит фоновые службы, скомпилирует бота и пропишет сервис в systemd:
```bash
sudo ./install.sh
```

## Список команд

Команды отправляются в личные сообщения боту. Поддерживаются префиксы `!`, `/`, а также ввод без префикса.

### Воспроизведение и управление:
- `p [запрос / ссылка]` — Воспроизведение, пауза или возобновление трека
- `u <ссылка>` — Воспроизведение прямого аудиопотока, интернет-радио или файла
- `s` — Остановка воспроизведения
- `n` — Следующий трек из очереди/списка
- `b` — Предыдущий трек из истории
- `c` — Информация о текущем треке, позиция, хронометраж, громкость
- `seek <ММ:СС>` / `st <секунды>` — Прямая перемотка на конкретный таймкод (например `seek 02:15` или `st 90`)
- `sb [сек]` — Перемотка назад (по умолчанию 10 секунд)
- `sf [сек]` — Перемотка вперед (по умолчанию 10 секунд)
- `v [0-100]` — Уровень громкости
- `sp [0.5-2.0]` — Скорость воспроизведения
- `bb [1-20 / on / off]` — Усиление басов (Bass Boost) от 0 до 20 дБ
- `nc [on / off]` — Режим Nightcore: ускорение с повышением тональности 1.25x
- `slow [on / off]` — Режим Slowed: замедление звучания с понижением тональности 0.85x
- `8d [on / off]` — Эффект 8D Audio: вращение стереопанорамы по кругу
- `fx [off / reset]` — Показать список активных эффектов или отключить их
- `dl [запрос]` — Скачать трек в MP3 и выгрузить его в хранилище файлов канала TeamTalk
- `m [normal / single / all / random]` — Режим воспроизведения
- `f` — Список избранных треков
- `f +` / `f add` — Добавить текущий трек в избранное
- `f - <номер>` / `f del <номер>` — Удалить трек из избранного
- `r` — История недавних треков
- `gl` — Получить ссылку на текущий трек

### Очередь:
- `qa <запрос>` — Добавить трек в конец очереди
- `ql` — Показать треки в очереди
- `qr <номер>` — Удалить трек из очереди по номеру
- `qc` — Очистить всю очередь
- `qs` — Пропустить текущий трек очереди

### Поиск:
- `sr <запрос>` — Расширенный поиск по названию
- `sl <номер>` — Выбор трека из результатов поиска
- `slc <1-15>` — Количество выводимых результатов поиска

### Навигация и каналы:
- `come` / `go` / `jc` — Бот заходит в ваш текущий канал
- `jc <ID или имя> [пароль]` — Переход бота в указанный канал
- `sv [yt / ytm]` — Переключение источника музыки (YouTube / YouTube Music)
- `h` — Справка по командам бота
- `a` — Информация о разработчике

### Команды администратора:
- `cookies [текст]` — Просмотр или обновление `cookies.txt` через ЛС
- `cn <никнейм>` — Изменение ника бота
- `cs <текст>` — Изменение статусного сообщения бота
- `cg <m / f / n>` — Изменение пола бота
- `cl <ru / en>` — Изменение языка бота
- `cm` — Переключение отправки сообщений в канал
- `va` — Переключение режима передачи голоса
- `bc [add / del / list]` — Блокировка и разблокировка команд для пользователей
- `ua [add / del / list]` — Управление администраторами
- `ub [add / del / list]` — Управление черным списком
- `l` — Блокировка бота (доступ только для админов)
- `sc` — Сохранение настроек в config.json
- `cc` — Очистка кэша и истории воспроизведения в БД
- `gcid` — Получить ID текущего канала
- `rs` — Перезапуск бота
- `q` — Завершение работы бота
